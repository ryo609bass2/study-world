# STUDY WORLD

小学5年生向けの学習型3Dサンドボックス。島を歩き、算数で資源を集め、マイアイランドに建物を置きます。日本語のブラウザゲームです。

## 起動

Node.js 24 LTS と npm を使います。npm レジストリに接続できる環境で、このフォルダを開いて実行します。

```sh
npm ci
npm run dev
```

Vite が表示した URL をブラウザで開きます。同梱の `package-lock.json` で依存関係を固定しています。開発時と公開時はアクセスする URL が変わるため、セーブを引き継ぐ場合は JSON を書き出して読み込んでください。

## 遊び方

1. **島の冒険**から匿名プロフィールを作成します。通常・サポートのどちらかを選べます。
2. 宝箱の近くで開けます。算数を3問解き、クラフトで小さな家を選びます。
3. 明るい緑の建築エリアで位置・向きを決め、**ここに配置**を押すと中央広場が開きます。
4. 中央広場の案内係から森林・鉱山へ。橋の資材の問題を解いて橋を直すと、鉱山区画が開きます。
5. **学習クイックスタート**からも採掘・オビーを選べます。採掘はタイムリミットがなく、WebGL非対応でも利用できます。

| 操作 | PC / Chromebook | タッチ |
| --- | --- | --- |
| 移動 | WASD・方向キー | 移動スティック |
| 走る・ジャンプ | Shift・Space | 走る切替・ジャンプ |
| 調べる・採集 | E または F | 近くに出るボタン |
| カメラ・拡大縮小 | 右ドラッグ・ホイール | スワイプ・ピンチ |
| 建築・持ち物 | B / I | 建築・持ち物 |
| 建築位置・回転・確定 | 地面をクリック・R・Enter | 地面タップ・回転・ここに配置 |
| 学習・マップ・戻る | L・M・Esc | 学習・マップ・閉じる |

設定から文字拡大、シンプルHUD、動きや音量、左利き用タッチ配置を変更できます。学習の難しさとオビーの操作難易度は別々に設定できます。

## セーブ

セーブは IndexedDB にプロフィールごとに保存します。プロフィールを切り替えられます。共有端末でのデータ管理は学校の運用に合わせてください。プロフィールには氏名を入力する必要がありません。セーブデータや学習履歴は外部に送信しません。

- リロード後はプロフィールを選びます。中断中のミッションを再開できます。
- 設定の「セーブデータ」から JSON を書き出し・復元できます。読み込みと初期化の前に確認が出ます。
- ブラウザの消去設定や利用環境の切替でセーブが消えることがあります。学習履歴を保持する場合は学校のルールに従って JSON を保管してください。

## 検証

```sh
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:storage
npm run test:e2e
```

`npm run test:e2e` は、ビルド済みの `dist` をローカルの `/study-world/` に配信してブラウザシナリオを実行します。実施済みの検証、未検証項目、未実装項目は [IMPLEMENTATION_STATUS.md](IMPLEMENTATION_STATUS.md) を参照してください。

## GitHub Pages

このフォルダを GitHub リポジトリのルートにします。`npm ci` で依存関係をインストールし、型検査・テスト・ビルドを実行してください。GitHub の **Settings → Pages → Source** で **GitHub Actions** を選択します。同梱のワークフローは `main` の push または手動起動時に検証後の `dist` を配信します。Vite の相対ベースと単一ページの画面遷移を使うため、リポジトリ名による固定のアセットパス設定は不要です。

## ソースの構成

| `src/app` | シナリオ・進行状態・領域横断のコマンド |
| `src/engine`, `src/worlds` | 操作・描画・島の定義 |
| `src/learning`, `src/minigames` | 問題生成・解答判定・ミニゲーム |
| `src/building`, `src/progression` | 建築・カタログ・成長 |
| `src/persistence` | IndexedDB・JSON検証・バックアップ |
| `src/ui` | React UI・個別設定・音 |
| `tests`, `e2e` | ドメイン・ブラウザ検証 |

素材の内訳は [ASSET_LICENSES.md](ASSET_LICENSES.md) を参照してください。
